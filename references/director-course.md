# 《导演必修课》· 系统实务版

本套教材围绕读戏、表演、空间、摄影、美术声音、剪辑、类型和实践形成完整的前期创作学习链：**8部、24课、12个场面案例、8个练习和1个完整综合创作示范**。这是覆盖本skill工作所需领域的系统教材，不是几条镜头公式，也不声称穷尽所有导演流派、电影史或替代现场经验。

## 阅读方法

开始新项目先执行 [导演创作与反向审阅](directing-practice.md)，再用本页带着剧本的问题选读正文。若首次使用、不知道问题在哪里，先读第一部与第三部，之后根据人物、摄影、剪辑等实际困难选读；不要每镜重新读全套，也不要把24课做成24项表格。完整自学可以顺序读八部，做一次综合创作，再换题材检验。

| 当前创作问题 | 先读 |
| --- | --- |
| 梗概很短，不知道这场戏真正发生什么 | 第一部 |
| 人物像执行指令，表情和口气重复 | 第二部 |
| 不知道跟随谁，人物换边或瞬移 | 第三部 |
| 固定太多、乱运镜、竖屏塞不下信息 | 第四部，随后第三部 |
| 背景像样板间，光色空泛，声音只会加紧张音乐 | 第五部 |
| 单镜都清楚，连起来平淡、拖沓或难懂 | 第六部 |
| 更换类型、群戏、动作、纪实或跨集重访 | 第七部及相关案例 |
| 设计无法落地，H3误解，预演与样片不一致 | 第八部 |

## 案例与实践

[十二个场面案例](director-course/cases.md)：悬疑警告、生活对话、车辆追逐、喜剧、亲密、冲突、悲伤、恐惧、群戏、无对白、风格化与跨集重访。每例说明另一种合理选择，以及改法可能损失什么；不是镜头库随机抽签。

[练习册与综合创作](director-course/workbook.md)：八个练习可选做；综合作品《闭店前的钥匙》给出原始材料、初稿、另一拍法、选定的完整四镜和一次回看修改。它没有照搬悬疑例中的推近，而是因为手部行动重要而保留固定。

[资料与观点边界](director-course/sources.md)：区分一手访谈、常用概念和本地原创教学；保持方法差异，不编造名导观点或宣称看过未看的视频。基础阅读能改变当前决策，不等于模型永久接受训练。

## 与生产流程衔接

学习发生在创作中：先理解完整场面，形成简短拍摄构想，遇到真正的取舍再比较方案，选定后写三栏分镜，完成全段后回看并修改。不要向用户展开全部练习过程；把构想、具体改动及仍有的疑问放进现有审阅说明，随分镜一次确认。主要叙事改动仍按既有分析确认规则处理。

中文正文仍是场景→镜头运动→人物运动；内部可以自由思考，不能把表演层次强制切成三拍。七项导演审阅保持不变：sequence_note 记录全段选择和回看结果；相关逐镜创作问题落在 narrative、performance、pacing、continuity 等现有项；standards 负责表达与格式。不要给审美加正则评分、运动配额或“教材已读所以通过”。

教材适用于不同目标系统。官方适配在导演方案之后，不能把教材的栏目或感受词写成模型私有语法。技术限制反证方案时提出具体修改；布局、预演、人物四图、场景资产、跨集继承与确认流程沿用现有skill。教材和练习不自动进入生产清单，不能把示范选定稿登记为用户批准。
