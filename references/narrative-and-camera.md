# 剧情节奏、人物与文字分镜

先按 [二次创作](creative-development.md) 保留原文并写可阅读的改编场景，确认导演组的情绪起伏，再拆分镜。节奏包括信息、人物理解与行动、观众情绪的变化，不等同于切镜速度；适用于悬疑、生活、爱情、喜剧等题材，不套用固定秒数、镜头数或“每几秒一个反转”。

## 观众何时知道什么

按本段用途选择需要分析的事件与转折，不给纯状态或过渡硬加转折。对重要节拍说明原文依据、人物眼前目标、阻力、观众与角色各自已知的信息、该段新增或推翻了什么，以及结束时发生的变化。使用 explicit / inferred / proposed 标记依据；改动事实、因果、关系、结局或新增关键行为时列为提案，不藏入英文。

用户需要曲线或比较压力时可用紧张度 1–5，它只表示本片内部的相对戏剧压力，并说明原因。安静的羞怯、等待回应或压抑的争执也可以有压力，不必增加危险。区分情节风险、观众掌握的信息、人物情绪强度；揭示可能让人物更紧张，却让观众获得解释、短暂放松。

根据本段用途和因果选择节奏，不套统一的升级链。检查：

- 新信息出现后，是否有足够的感知或反应让观众理解？反应可与动作共处一镜，不必须加面部特写。
- 连续反应镜是否重复同一情绪？若后一个镜头没有新判断或选择，合并或改变功能。
- 是否一次投放过多关键信息，让观众同时读字、找物件、听关键台词？合理错开出现时间。
- 高压段后的停留，是消化新事实、改变关系，还是仅拖时长？缓冲也需要功能。
- 按段落用途选择结束位置，可以完成、停留或留下问题，不把所有结尾写成悬念，不擅自增加结果。

## 用选择建立人物差异

在 character-analysis.md 为主要角色建立简短、可用的角色依据：

| 项目 | 内容要求 |
| --- | --- |
| 眼前目标与更深需求 | 想在这一场得到什么、为什么在意；后者不明时注明推断。 |
| 恐惧或损失 | 此刻不愿发生什么，不用没有依据的创伤身世补全。 |
| 已知与误判 | 到每个转折才知道什么，防止提前表现尚未获得的信息。 |
| 对人的策略 | 试探、回避、解释、讨好、控制、抵抗等，选择有依据的行为。 |
| 外在呈现与内在冲突 | 想给对方什么印象，真实想做什么，两者怎样冲突。 |
| 表达习惯及变化 | 言语节奏、目光、姿势、物件使用；少量有动机的习惯，不反复添加抽搐、吞咽等标记。 |
| 关系变化 | 信任、控制权或距离怎样变化，体现于回应和选择。 |

不能用年龄、性别、职业直接推出性格。同样的害怕可以导致核实、隐藏、反驳或服从，由当前目标与信息决定。不为突出人物而强加口癖、疾病、秘密或亲缘关系。

## 心理如何变成可拍的反应

对重要转折建立“刺激—理解—冲动—克制或选择—可见行为—余波”的因果链。它是分析工具，不要求每个环节独立拍摄或机械写出六种微表情。

- 刺激：实际看见、听见或读到的事件。先有可感知事件，再有反应。
- 理解：角色怎样解释事件，允许误解；仅使用其此时已知的信息。
- 冲动与克制：本能想做什么、为何不立即做；不能把克制都写成僵硬不动。
- 选择：主动采取什么策略。鲜明来自选择，不是表情数量。
- 可见行为：眼神落点、姿态、手部动作、距离或有意义的停顿；通常抓一个主要变化，必要时辅以一个次要变化。
- 余波：状态延续到下一镜，不在切镜后恢复中性；放松的手不能下一镜无原因重新紧握。

psychology 保留意图、情绪进入/退出及依据标记；performance 写可表现的动作。英文目标正文主要呈现可见、可听的结果，心理词只作简短表演方向，不写不可观察的长篇解释。

无人物插镜的 psychology、performance 可简短注明不适用及原因；如有观众信息功能，写入相应叙事依据。不要为填字段凭空增加人物反应。

## 表演描述：行为有来由，细节按需选择

先理解人物正在经历什么，写出主要行为；顺势的小动作和细微反应可按需补充，也可以省略。这是表演层次，不是动作清单；眨眼、呼吸或不安只是用户举例，不构成限定、必选项或默认组合。实际细节由本场经历、角色习惯、人物关系与镜头需要决定，可体现于视线、手部、姿态、重心、动作节奏、持物方式、人与人距离或声音等不同方面；这些也只是开放示例，不要求逐类填满。该层次写入三项正文的“人物运动”，并同步到系统原文与中文对照；整镜按 [三项分镜规范](three-part-storyboard.md) 展示。

- 经历：交代此刻的具体处境、正在处理的事情或刚收到的刺激，以及想完成或掩饰什么。先让观众理解行为的来由，不仅贴“紧张”“害羞”标签；心理推断记入 psychology，目标正文用可见、可听的事件承载。
- 小动作：从当前任务、物件使用与习惯自然发生；选它应有表现作用，不随意新增关键道具或转移重点，承接上一镜状态。
- 细微反应：有需要时写当前取景能辨认的具体变化，不以固定动作清单代替人物反应，也不要求在主要动作之后追加一拍。

写作层次不等于强迫表演分三拍：动作和细微反应可以重叠，突发刺激引起的即时反射不能被延迟。只写当前景别能辨认的反应：手部插镜不同时要求看清眨眼；奔跑远景以步态或姿势呈现，不硬塞面部细节。无人物镜不强行套用此规则。

导演检查核对经历与动作的因果、细节是否可见、人物差异及前后延续；去掉重复或抢戏的微动作，不以“出现了眨眼／呼吸关键词”判定表演自然。

## 每一句台词都有说法

dialogue 保留当前已确认改编稿的逐字台词（用户要求忠于原文时保留原台词）、发声者、画内/画外/内心旁白，以及画面文字的区别。可用 L1、L2 等本镜内编号与 delivery 一一对应。delivery 是单独的可编辑字段，至少说明语气和有作用的说话方式，不能给整场只贴一个“愤怒”标签。

语气可以是慵懒、愤怒、害羞、疲惫、试探、冷淡，也可以有“表面轻松、实际上防备”的层次，但应与心理和关系相符。进一步选择真正影响表演的维度：

- 语速、音量、停顿、重音、气息、咬字与语尾，不要求每句填满所有维度。
- 写清在哪个词句间停顿、强调哪个词，以及怎样服务意图。
- 一句中若语气改变，明确由哪个词或事件触发；保持不同角色的表达差异。
- 区分怒意与大声、羞涩与结巴、慵懒与困倦；无依据不加吼叫、口吃或删吞台词。
- 旁白也要写口气，画面嘴部动作不能误变成在说内心旁白。短信只为可见文字时，delivery 明写“无发声，保留阅读时间”。

示意：慵懒可用舒缓语速、句尾略拖；愤怒可用压低音量、咬字变重、质问前停顿；害羞可用轻声、回答前短暂停顿、语尾收住。是否回避视线另写在 performance；这些都不是固定的人格公式。

转换英文时，将语气和说话方式放在对应发声者及该句对白附近，原台词不变。使用已核验的目标系统表达方式，不发明 emotion 标签。实际语音资产仍不由本 skill 自动生成。

## 将节奏落到镜头和时间

仅在生产方案选定后整理每镜数据：purpose、description、framing、action、camera、dialogue、continuity、psychology、performance、delivery、rhythm、duration。镜号与节拍、资产及已有布局版本仍保存在 manifest；未制作布局时注明待验证，不伪造机位验证结果。

最终正文按 [三项分镜规范](three-part-storyboard.md) 组织为场景、镜头运动、人物运动；具体字段映射、旧稿整理与适配规则以该规范为准。先理解经历，再确定取景与表演；不将展示顺序误写成事件时序。

framing 写景别、观察方向与关键可见区域；action 写动作起止；camera 选定一种方案，运动时说明起幅、结束构图、幅度与速度。不能把“固定或推近”当定稿。一个取景无法同时容纳不同距离上的关键细节时，拆镜或写明可行的运动/焦点转换，不能在一镜内暗藏多次切镜。

rhythm 说明该镜承担铺垫、信息投放、反应、核实、缓冲、推进或悬停；按实际需要安排进入、事件、反应、停留和出镜点。对话可与动作重叠，不把全部时间机械相加。

时长先作为提案。重要台词优先实际朗读估时，记录方式、说话速度与停顿；若只有文字估算，明确标记，不能谎称已测量。说明充分时可让用户确认时长提案，后续音频/预演再校准，不把普通分镜卡在未请求的配音生产上。短信还需留识别来源和阅读正文的时间，字数不能自动证明可读。

区分故事钟点、全片剪辑时间、单次生成片段内切点；省略有可辨认过渡。交叉剪辑写明切入时人物位置、动作接点及事件时间是否重叠。心理停顿可以帮助调度，但不能只为凑路线强迫人物无理由发呆。

## 输出与导演检查

写 narrative-analysis.md（节拍、信息差、节奏变化）与 character-analysis.md（角色依据、转折与表达差异），登记入项目。新审核项目用完整中文 JSON 配合 review-init --storyboard-file，不能仅导入摘要就当作完整导演稿。

有审核项目时，review/state.json 是当前中文导演稿、系统文本、语气与版本的权威；camera-plan.md 若作为展示文档，须从当前数据导出并标注版本。修改时同时核对摘要和各字段，避免互相矛盾。

用户确认前按 [导演检查协议](director-review.md) 完成“结构完整—同步—全段与逐镜判断”。自动校验通过或译文存在不等于艺术质量。检查反应的刺激依据、通过选择显现的人物差异、逐句口气、反应与阅读时间、取景可行性和翻译保真。示例见 [表演与语气示例](performance-examples.md)。
