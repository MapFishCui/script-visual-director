# 空间预演参考流程

默认用三维预演提供视频生成的空间依据：人物在哪里、何时移动、镜头如何观察。最终外观和表演细节由外观参考与提示词表达，不要求先制作成品人体动画。

## 制作顺序

1. 根据剧本写中文导演稿，明确镜头、人物目标、时长与互动，不因建模方便改变核心事实。
2. 建立统一尺度的场景，明确门窗、桌椅、通道、入镜面与主光方向。优先细化入镜、被操作、影响遮挡和光影的物件；茶杯茶壶等可以生成或导入模型，检查尺寸、朝向、接触面与来源，不要求所有背景小件都高精。
3. 普通站位和走位用圆柱/胶囊身体加球头，明确角色编号、身高和朝向；坐下、伸手、拿放升级为关节人偶；精确表演再用成熟骨架、关键帧或 Kimodo。
4. 动画化根节点位置、朝向及摄影机，交代进入、停留、转向、离开和接触时刻。人物、持物和门的状态沿同一时间线连续，不在切镜时重置。占位体平移只验证路线和时机，不代表已完成步态。
5. 输出连续参考视频，观看全段并抽查转身、遮挡、切镜、接触前后。修正实际空间问题，不用提示词掩盖已知冲突。
6. 配合独立人物外观参考、动作提示词及中文对照交付。核对目标工具实际支持的参考视频、图片、时长与输入槽位。

人物外观参考继续遵守纯背景规范。占位人偶不替代身份参考；场景与走位不必等待人物四视图齐全才开工。

## 每段交付说明

项目内保存 `spatial-reference.md`，标明流程为 `spatial-reference-v1`，记录镜号、角色编号、场景/道具版本、实际视频路径、帧率与时长、角色起止位置/朝向、路线、停留、关键接触时刻及外观参考。区分已验证的空间、摄影机与精确动作，列出未制作的表演。

同时保存真实 `.blend`、参考视频、必要关键姿态图、提示词与中文对照、来源记录。未渲染的参考视频保持待办。场景、走位或机位改变后重新输出受影响片段并更新版本；用户批准和几何检查分别记录，不继承旧版本批准。

提示词明确：

- 保留人物相对位置、路线、到达与停留时机、摄影机运动、场景布局及指定遮挡。
- 将几何人偶替换为对应人物外观，去掉编号和辅助标记。
- 描述动作目的、情绪、速度、力度、视线和必要接触，其余自然肢体细节允许模型发挥。
- 不为丰富动作改变核心走位和互动；这些是创作意图，不保证视频模型严格执行。

若目标工具不支持参考视频，明确说明并改用它支持的关键帧/图片，不声称它读取了连续预演。九宫格为可选方案。

## 精确互动与 Kimodo

递杯应交代持有者、交接位置、松手时刻；拥抱和打斗需明确双方接触、相对朝向及先后关系。必要时添加关节人偶关键姿势或骨架动画，再让模型补充自然细节。Kimodo 是可选动作来源，不是普通走位的安装前提，不保证一次生成准确双人互动。

## 现有工具边界

- `model-validate`、`model-build` 支持已有 `actor` 关节代理及根节点关键帧；导入 `asset` 仍需项目锁定和来源记录。内置 actor 不是圆柱球头专用造型；最简占位可由项目内 Blender 脚本制作，不冒充新增 JSON 组件。
- `model-build` 输出场景和检查静帧，不自动输出全段视频。连续动画与摄影机由项目内 Blender 脚本制作，参考 [本地预演](local-previs.md)。旧绑定/登记命令仍有真实前置状态，不为新流程伪造旧审批。
- `scene_plan.py` 的成熟绑定和 rig_pose 用于精确动作；简单代理走位不强塞进它，也不把 object_motion 当人体表演。
- 新空间预演模式尚无专用审核网页或自动视频模型调用。维护上述实际文件，不通过登记假九宫格冒充进度。
- 已有九宫格或布局优先项目继续原流程；用户选择迁移时保留历史资料，并重新记录新流程实际完成情况。
