# 预演到场景资产

预演选择生成时，先完成当前版本预演检查与用户确认，再生产资产；选择跳过时依据已确认布局和机位，明确动态遮挡未验证。用户只要求开发流程或暂停生图时，不启动资产生产。

## 方位与形态绑定

背景图是可复用的场景参考资产，不是 AI 视频的首尾帧。根据所需空间方向和状态组织资产，同一方向可服务多个镜头；不同机位或几何状态不能仅换一段文字复用不匹配图片。

为每项场景资产在项目 `scene-reference-plan.json` 中记录：资产编号、所服务镜号、布局编号与版本、摄影机编号、position / target / yfov / aspect、预演运行与逐镜索引路径、选用摄影机诊断帧的帧号和原片时间、门窗及道具状态、场景美术基准版本。该文件作为 handoff 文档登记；不是新增 manifest 顶层字段。manifest 中使用现有 layout 和 asset dependencies 绑定确切版本。

- 方位以布局坐标和摄影机观察方向为准，不能把画面左侧当成场景固定左墙，更不能把世界坐标轴直接称作东南西北。
- 几何锁定房间比例、门窗洞口、柜台与货架轮廓、通道宽度、物件相对位置和可见遮挡。外观可补材质、商品陈列、细节、色彩和照明，但不能让陈列侵入已验证路线。
- 运镜涉及多个观察方向时，选择能覆盖空间关系的诊断视角；单张图片不能代表整条运镜已经验证。需要时扩展另一方位资产。
- 除非本项明确需要，场景资产默认不包含演员或白模人偶。移除人偶时保留场景结构，不能把橙蓝人偶、俯视图和调试标签变成背景美术。

## 制作顺序

1. 完成人物、场景、道具需求清单；人物按四张独立图规格制作，不因场景流程改变交付规格。
2. 从已确认预演选与目标方位相符的纯摄影机诊断图；先查看，确认构图、几何和机位正确。不要用俯视拼图冒充透视参考。必要时从相同场景状态和机位另渲染无演员白模参考图，不改几何。
3. 生成提示明确每张参考图的作用：白模提供方位、形态、比例、透视和遮挡；美术基准提供材质、风格和照明。实际将参考图传给图像工具，不能只在文本中写文件名。
4. 先生成代表方向的场景美术基准，检查后让用户确认；其他所需方位同时依据该基准和各自预演视角扩展。人物、场景及关键道具均先确认基准，再扩展。
5. 并排检查生成图与白模图：门是否仍在对应墙面，柜台、冰柜、员工通道是否保持相对关系，机位高度和消失方向是否合理，家具比例及视线遮挡是否一致。检查结果写入资产 review.note，不把图像模型的参考输入当作几何保证。
6. 不符时修订资产；若为了美术必须改变布局或机位，先回到空间阶段更新并重新检查受影响预演，不能用生成图反向悄悄替换已确认空间。

更改预演方向或场景状态后检查 scene-reference-plan.json 中的关联，并显式使受影响资产失效；不能仅凭布局版本未变就沿用旧视角。最终交接同时提供实际图片与这些来源映射，使下游知道每张背景对应哪段预演。
