# 二次创作：先让段落成立，再拆技术任务

用户提供的是剧本、梗概或一句话，都可以进行导演层面的二次创作。目标是让观众经历有因果、有情绪变化的场景，不是把每句话翻译成一镜，也不靠增加镜头数、配乐词或华丽运镜填满时长。不能承诺仅靠提示词一定得到电影效果。

先执行 [导演创作与反向审阅](directing-practice.md)，再按 [《导演必修课》](director-course.md) 理解整个场面，再决定如何丰富；用 [场面案例](director-cases.md) 比较拍法的收益与代价。不要照搬教材中的人物行为或镜头序列。

## 可自主丰富的范围

保留原文为 source.md。默认可提出并写出不改变核心事实的环境细节、生活动作、人物潜台词、反应与克制、空间调度、声音先行、信息隐藏与揭示、自然过渡。用户未提示“加特写”时也应主动选择必要的局部镜头；普通导演选择不逐项提问。

以 explicit / inferred / proposed 区分原文、推断与创作。新人物、新秘密、关键道具证据、关系、事件因果、结局或实质台词改写，应在改编稿中明确列出并随剧情分析一起确认；不要等到英文里才偷偷加。用户已授权的改编范围无需再次逐项询问。用户要求忠于原文、简短或固定时长时遵守其限制。

先写 creative-treatment.md：

- 一段可连贯阅读的中文改编场景，保留叙事顺序与对白，让用户先感受这场戏；不能只给技术字段表。
- 每个导演组的情绪进入、主导问题、铺垫与变化、停留和结束落点；写清观众与角色各自知道什么。
- 新增／调整的细节及其作用，注明推断或提案；重要设定改动集中列出。
- 创作时长及估时依据，区分台词、阅读、动作可重叠的时间；53秒、48秒是可行的段落长度示例，不是模板或配额。

将该文登记为 analysis，并在 review-init 的 analysis_files 中与剧情／心理分析一同指定，使后续确认与版本失效能追溯到创作稿。先在持续项目页展示；确认后才成为分镜依据。已有项目新增或修改改编稿时更新审核配置的 analysis_files，保留旧稿与原始剧本，复核受影响分镜。不要直接改写用户已批准的生产项目。

## 局部 → 局部 → 局部 → 整体

它是一种有目的的信息揭示方式，不是每场必须执行的四镜公式。每一个局部都应增加信息或改变理解，整体镜头再解释这些细节之间的关系。局部数量、景别顺序和揭示速度随戏调整；可以是两个局部，也可以一镜运动逐步揭示。不得用密集特写替代必要的空间交代。

示例：原文只有“雨夜，女孩在便利店复习，一个陌生男人进来”。可以提出：

| 画面选择 | 给观众的体验／功能 | 连接依据 |
| --- | --- | --- |
| 铅笔停在习题边，指腹抹过橡皮屑 | 先进入她专注但疲倦的日常；无需额外旁白解释 | 同一只手，书页与笔的位置保持 |
| 练习册一角贴着收银键盘，制服袖口掠过书角，翻页前稍作停顿 | 逐渐看出学习与工作挤在一起，补充场所信息 | 道具必须与已确认服装设计一致，不强行造物 |
| 门边地垫落下一串水滴，鞋停住；先听到门铃 | 注意力被画外来客打断，暂不揭示其脸或意图 | 水滴来自湿衣／鞋，地垫在门内，不让室内凭空下雨 |
| 转到能看清收银台、入口与两人距离的整体构图 | 解释前面局部属于同一场景，建立后续行动空间 | 人物此时仅到入口，不能瞬移到收银台 |

这只是待确认的导演提案，未规定固定秒数，也未替《雨夜来客》现有分镜改版。局部可以用声音桥、动作接点或视线连接，不应让观众误以为发生在不同时间地点。正面交代空间、长时间观察人物、画外揭示也同样可能适合该场戏。

## 人物和电影感来自选择

- 不把“害怕”固定翻译成瞪眼、抓柜台、连续三个面部特写。她也可能装作继续扫码、找理由询问、把手机悄悄移近；必须由当前目标、已知信息和性格依据支持。
- 对话不必须拍说话者。可以留在听者的理解变化上，或在有动机时拍双方距离；台词语气紧贴具体句子，服务试探、掩饰或迫使对方相信的策略。
- 细节必须有作用：建立生活、突出人物、埋设或回应线索、改变注意方向、解释空间。删掉后体验不变的重复局部应删掉，不能用“丰富”掩盖注水。
- 静止机位、画外声、停顿、负空间和视线有时比运镜更有效。只有信息、关系或情绪发生变化时才考虑移动或切镜；不要求每段推拉摇移。
- 相邻细节要形成变化，而非连续重复同一个情绪。整体揭示之后可保持一段完整表演，让观众消化，不马上继续碎切。

## 从创作到制作

先完成导演组的完整体验与创作镜头，再决定内部视频段。每段提示词都携带所属导演组的必要前情、进入／离开状态和声音连接，不把技术边界自动写成淡出、黑场或情绪收尾。H3参考流程的15秒预算只作用于生成任务。

跨任务长镜头需要明确续接、运镜与表演连续性方案并实测；当前常规任务表按完整镜头分配，不宣称自动实现跨段无缝长镜头。如果单镜超限，先提出不损伤叙事的切点或目标工作流调整，不能改几个编号就冒充连续镜头。

导演检查时问：删去该细节损失了什么？何时从局部理解到整体？人物什么时候获得信息并改变策略？技术切段是否破坏了情绪？将判断记录在现有 narrative、character、pacing、continuity 项中，不用新打分表代替创作。
