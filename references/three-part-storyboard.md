# 三项分镜写作规范

每格交给用户审阅的正文只写三项，顺序为 **场景 → 人物运动 → 镜头运动**。镜号、时长、版本是元数据；心理、叙事、节奏和连续性是内部创作与检查依据，不展开成更多正文栏目。适用于新稿及用户要求整理的旧稿。

## 三项内容

- **场景**（description）：地点、时段、光线／环境状态、关键物件与人物起始位置。必要的画面文字和环境声放在此项。只写本镜相关信息，不重复整个场景设定。
- **人物运动**（action）：正在经历的具体处境或刺激 → 顺势发生的行为与小动作 → 少量细微反应，写到动作结束或切出状态。台词及逐句口气写在对应人物行为附近，旁白注明画外／内心，避免错误口型。根据处境、习惯、关系自然选择细节，动作种类开放；可以重叠发生，不强行三拍，不机械增加微动作。无人镜注明无人，描述画内物件变化或静止即可。
- **镜头运动**（camera）：景别、机位／观察方向、构图、固定或运动；运动时说明路径、速度、起止构图及跟随对象。写清与人物动作同步或触发的关系。固定镜头也是完整方案，不必为了填栏而运镜。

创作时先理解人物与事件，再确定取景能呈现什么、安排表演；“先定镜头，再放动作”保留为构思和可拍性检查原则。最终三项展示遵循用户最新指定顺序，不再强制镜头文字排最前。

## 示例（表演提案）

**场景：** 凌晨便利店，冷白灯亮着。林夏坐在柜台员工侧，摊开的课本靠近手边，玻璃门外持续下雨。

**人物运动：** 她复习到同一行又停住，试着把注意力留在课本上；顺手压平翘起的书角，指尖在纸边停了片刻，才继续往下读。

**镜头运动：** 固定中近景，从员工侧斜拍，脸与双手同在画内，课本落在画面下部；在她重新读下去后切出。

这是写作示例，不添加到用户已确认剧本。无需每镜都有台词、物件互动或微表情。

## 数据、编辑与适配

沿用现有字段以保留版本和历史：三个主字段 description、action、camera 存完整三项正文；framing、performance、dialogue、delivery 是对应内容的内部拆解，purpose、psychology、rhythm、continuity 支持分析，duration 保留时长。Codex 初始化时一并写全，不能靠正文三栏减少后台推理。

页面主区只显示三项，其他字段收进默认折叠的“创作依据与时长”。用户改主栏后，Codex 根据当前编辑与历史核对内部拆解字段：必要时先用 review-edit 保存完整中文，重新 review-export 后再同步。主栏的明确新意图不能被旧拆解字段覆盖；若用户同时改动产生冲突，先解决中文冲突，不在英文里偷偷选择。仅展开／折叠不修改数据、版本或批准。

旧项目可能在 description 混有动作和机位；页面改标签不会自动理解和重写旧稿。用户要求整理时，先基于完整旧稿形成三项并保留台词、语气、时长和状态，再走正常修改、同步与确认流程；不重建项目或假称原有25镜已完成语义转换。

通用目标正文可使用 Scene / Character action / Camera 三段及对应中文三项。专用目标保留必需的镜号、时间码、外层结构、发声者标记；将三项内容适配到合法位置，不强插未知标签或删去目标必需字段。中文对照须完整保留实际系统原文的信息。人工导演检查同时检查三项简明、事实与台词保真、表演自然及取景能否呈现，不能用关键词检查替代判断。
