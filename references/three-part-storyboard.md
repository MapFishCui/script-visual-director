# 三项分镜写作规范

每格交给用户审阅的正文只写三项，顺序为 **场景 → 镜头运动 → 人物运动**。镜号、时长、版本是元数据；心理、叙事、节奏和连续性是内部创作与检查依据，不展开成更多正文栏目。适用于新稿及用户要求整理的旧稿。

三项是选定方案的展示与执行格式，不是生成故事的思维模板。先按 [导演创作与取舍](directing-practice.md) 形成完整场面，再组织这三个字段。

## 三项内容

- **场景**（description）：地点、时段、光线／环境状态、关键物件与人物起始位置。必要的画面文字和环境声放在此项。只写本镜相关信息，不重复整个场景设定。
- **镜头运动**（camera）：景别、机位／观察方向、构图、固定或运动；运动时说明路径、速度、起止构图及跟随对象。写清与人物动作同步或触发的关系。固定镜头也是完整方案，不必为了填栏而运镜。
- **人物运动**（action）：写处境中的主要行为及结束或切出状态；小动作、细微反应仅在有表现作用时补充。台词及逐句口气写在对应人物行为附近，旁白注明画外／内心，避免错误口型。根据处境、习惯、关系自然选择细节，动作种类开放；可以重叠发生，不强行三拍，不机械增加微动作。无人镜注明无人，描述画内物件变化或静止即可。

创作时先理解人物与事件，再确定取景能呈现什么、安排表演；“先定镜头，再放动作”同时落实到最终文本顺序：场景交代环境后，先写景别、机位、构图与运镜，再写画内人物动作；英文原文、中文对照、任务内每镜与页面编辑栏保持一致。描述顺序不是事件时序，同时运镜和表演仍须写成同时发生。

## 数据、编辑与适配

沿用现有字段以保留版本和历史：三个主字段 description、camera、action 存完整三项正文；framing、performance、dialogue、delivery 是对应内容的内部拆解，purpose、psychology、rhythm、continuity 支持分析，duration 保留时长。仅生产初始化时整理完整字段；它们是选定方案的数据拆解，不是额外创作任务。不适用的心理、表演或发声记录简短写明不适用原因，不为填满字段增加内容。

页面主区只显示三项，其他字段收进默认折叠的“创作依据与时长”。用户改主栏后，Codex 根据当前编辑与历史核对内部拆解字段：必要时先用 review-edit 保存完整中文，重新 review-export 后再同步。主栏的明确新意图不能被旧拆解字段覆盖；若用户同时改动产生冲突，先解决中文冲突，不在英文里偷偷选择。仅展开／折叠不修改数据、版本或批准。

旧项目可能在 description 混有动作和机位；页面改标签不会自动理解和重写旧稿。用户要求整理时，先基于完整旧稿形成三项并保留台词、语气、时长和状态，再走正常修改、同步与确认流程；不重建项目或假称旧镜头已完成语义转换。

通用目标正文可使用 Scene / Camera / Character action 三段及对应中文三项。专用目标保留必需的镜号、时间码、外层结构、发声者标记；将三项内容适配到合法位置，不强插未知标签或删去目标必需字段。中文对照须完整保留实际系统原文的信息。人工导演检查同时检查三项简明、事实与台词保真、表演自然及取景能否呈现，不能用关键词检查替代判断。

## 直白表达

写清谁在何处、摄影机能看到什么、人物如何移动以及动作结束的位置。含糊的“留一拍”“保留视线空间”“重点看她接受事实”须改成具体画面或移至内部依据。不得为消除含糊擅自新增关键剧情；常规构图细化按原意提出并随分镜审核。H3目标正文遵循 [官方结构与直白描述](h3-handoff.md)，三栏标签仅用于本地编辑，不能自称官方语法。
