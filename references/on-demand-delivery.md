# 按需交付：参考图与提示词

用户可以只做参考图、只写目标系统提示词，或同时要两者。无需完整剧本，不强制分析报告、分镜表、平面图、Blender、审核网页或阶段逐项确认。简短理解情节、视觉重点和必要连续性后，直接制作所需产物。没有必要运行 Python 时不建立虚拟环境；使用编译器时沿用 skill 虚拟环境。

## 人物背景要求适用于全部模式

人物身份、服装或体型参考图，无论按需单张、基准图、局部图还是完整四图，均使用纯白无缝棚拍背景；张数和工作流不构成背景要求的例外。用户明确指定其他纯色或透明背景时遵循其要求。只有用户明确要求剧情画面、环境人像或保留场景时才带环境，且不能把它冒充纯背景人物资产。剧本提到某种环境不等于要求人物参考图带该环境。

按需只减少交付项与流程，不降低所选资产的质量要求。不因已经生成了带景图片就事后改称“按需场景参考”来判合格。生成前将纯背景要求传入实际生图调用，生成后看图核对；工具无法满足时如实标记待修正，不要求用户再次批准才执行原本已要求的背景修正。

## 按交付选择工作

**只要参考图**：只确定所需人物／场景／道具、画幅、风格和实际视角，不索要无关的视频参数。读取 image-production.md 并实际调用图像工具，查看结果后交付真实图片。用户明确要一张或特定视角就按该范围，单张人物参考同样使用纯白棚拍背景；要求完整人物设定资产时默认 character-reference.md 的四张原图及一张原尺寸合图。同一角色的扩展仍使用同一基准，需确认基准时只确认该对象，不新增上游制作关卡。

**只要提示词**：沿用已知目标系统与模式；目标未知时先给通用稿，只有要求可直接执行的专用格式而缺少必要信息时才询问。用户已有图片／视频时实际查看并明确每项用途；没有素材时可走文本模式，不为了标签生成图片。读取对应系统规范，交付目标文本和中文对照，不先要求用户确认另一套分析或白模。H3 读取 h3-official-skill.md 和对应官方指南：Ref2VA 使用 h3.py 独立编译，不必建立 review 或 groups；其他模式按指南编写，不能宣称已由 Ref2VA 编译器验证。

**参考图加提示词**：只生成支撑当前视频任务的素材，将真实结果编号，再写与这些图一致的提示词和中文对照。优先复用用户已有且适用的素材。若用户要求先确认基准，确认前可以给待绑定文字草稿，确认后再扩展和绑定；否则单次交付不额外要求分阶段批准。视频参考可选，不为了写提示词先制作白模。空间关系仅依据现有素材和明确描述，未做布局检查时不声称已验证几何。

## 文件、绑定与检查

- 独立任务保存到用户指定目录或当前工作区的输出目录，不能写进 skill 代码目录。可直接在对话展示图片、可复制提示词及中文对照；保存文件时提供实际可用链接，不强制创建 HTML。
- 不强制 manifest、queue、register、groups-sync 或阶段批准。独立文件明确用途与版本即可；H3 每份最终任务列出真实文件到 Picture／Video／Audio 的映射、使用目的和顺序。未取得素材的编号明确标为待绑定，不能声称可直接执行。
- 检查真实文件可读、提示词与图片一致、标签不串号、当前模式与单任务时长及素材限制合规。独立 Ref2VA 编译通过仅代表已覆盖的语法检查；没有 groups 校验时需自行核对文件绑定，不宣称完整项目就绪或 H3 实测通过。
- 用户要求的结果缺少工具时，明确哪些未完成；文字方案不冒充已生成图片。不自动调用未授权的收费 API。
- 完成交付即停止，等待修改或新要求，不自动追加平面图、白模、人物四图或整集资产。

## 既有项目与后续升级

在完整项目中临时要求单项试图／试写时，沿用适用的已确认设定，把新结果作为候选版本；不伪造被跳过的阶段批准，也不覆盖锁定资产。要正式纳入项目时再走现有登记和依赖检查。用户随后明确要求全套，复用已有成果并补齐所选流程必要条件，不无故重做；用户说“确认”只确认当前交付对象。


用户只要九宫格或九宫格加提示词时，读取 keyframe-grid-workflow.md 的创作与H3约定，按需交付；已有四视图则直接引用，不强制重新走四阶段或创建进度文件。九宫格是完整剧情画面，允许且需要剧情环境，不属于纯白背景人物身份资产。
