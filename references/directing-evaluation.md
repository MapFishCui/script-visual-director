# 导演创作行为试题

用于更新 skill 后的隔离试写，不是生产模板，也不要求每次跑全套。不生成图片或最终视频，不自动批准项目。需要独立评估时使用未出现在规则或教材中的输入，不给预定拍法；模型自评与独立评估分别标记。

## 题目

题库属于公开练习材料，不作为未见题测试。日常改进优先观察用户实际给出的新情节；不要求用户另备测试剧本。
1. 父亲给准备离家的女儿盛饭，两人始终没提离家的事。设计一场日常戏，不添加重大身世。
2. 求职者抱着纸箱挤进电梯，发现面试官也在里面。设计一个短喜剧场面。
3. 红车从右支路汇入主路，追上黄车并最终在黄车左侧并行。设计动作段落。
4. 女人独自收拾桌子，把两只杯子中的一只放回柜子。无对白，不指定悲伤或分手原因。
5. 两个朋友在明亮公园碰面，约好去吃饭。情节普通，允许轻松简洁，不需要悬疑反转。

## 观察点（不是唯一答案）

看题材是否改变拍法，日常是否有关系但未被硬加秘密，喜剧是否经营预期与时机，动作是否保留方位与可理解过程，无对白是否允许含混，普通会面是否免于公式化藏脸。是否主动发现创作空间、实际比较值得比较的方案、承认代价、发现真实漏洞并修订。局部、固定、运动、镜数和篇幅均不作为得分指标。

格式检查另外执行。任何一次试写都不证明职业导演水平；真实用户审阅与后续样片可以推翻文字判断。

## 保存真实观察，比较改动前后

对影响创作行为的技能修改，选择实际新情节或保留输入的练习，在隔离目录保存原始输入、初稿、修订稿与观察记录。记录技能 Git 版本、使用的模型（已知时）、题材和本次范围；注明是模型自评、独立评估还是用户反馈，不将练习材料称为未见题。

逐条记录真实问题、对应镜号或原句、修改动作与结果，例如无依据加戏、人物已知信息矛盾、方向关系无法成立、无效重复镜头。保留用户原反馈；没有反馈或视频样片就留空。比较同一输入在修改前后的结果，观察是否解决旧问题、是否引入新限制，不用格式通过或自评分数代替观看体验。

建议观察记录字段为 input_file、skill_revision、model、scope、draft_file、revised_file、reviewer_type、observations（每条含 evidence、change、outcome）、user_feedback、video_validation。本次代码回归只验证状态与交付，不声称已完成创作盲测或提升真实视频效果。
