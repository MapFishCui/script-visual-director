# 导演创作行为试题

用于更新 skill 后的隔离试写，不是生产模板，也不要求每次跑全套。不生成图片或最终视频，不自动批准项目。评估者先给题目与 skill，不给下面的观察点作为预定答案；模型自评与独立评估分别标记。

## 题目

1. 雨夜，夜班店员接待湿透的男人；他说店会爆炸。店员手机收到只有她能看到的警告。设计一段可读的场面和关键分镜，保留事件但可提出细节。
2. 父亲给准备离家的女儿盛饭，两人始终没提离家的事。设计一场日常戏，不添加重大身世。
3. 求职者抱着纸箱挤进电梯，发现面试官也在里面。设计一个短喜剧场面。
4. 红车从右支路汇入主路，追上黄车并最终在黄车左侧并行。设计动作段落。
5. 女人独自收拾桌子，把两只杯子中的一只放回柜子。无对白，不指定悲伤或分手原因。
6. 两个朋友在明亮公园碰面，约好去吃饭。情节普通，允许轻松简洁，不需要悬疑反转。

## 观察点（不是唯一答案）

看题材是否改变拍法，日常是否有关系但未被硬加秘密，喜剧是否经营预期与时机，动作是否保留方位与可理解过程，无对白是否允许含混，普通会面是否免于公式化藏脸。是否主动发现创作空间、实际比较值得比较的方案、承认代价、发现真实漏洞并修订。局部、固定、运动、镜数和篇幅均不作为得分指标。

格式检查另外执行。任何一次试写都不证明职业导演水平；真实用户审阅与后续样片可以推翻文字判断。
